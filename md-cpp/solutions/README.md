# 📘 Lời Giải Bài Tập — Khoá C Cơ Bản

Thư mục này chứa lời giải tham khảo cho **885 bài tập** (15 bài × 59 bài học) trong thư mục [md-cpp](../).

> ⚠️ **Lưu ý khi dùng:** hãy **tự làm bài trước**, chỉ mở lời giải khi đã bí hoặc để đối chiếu.
> Mỗi lời giải đều có code C chạy được, kèm giải thích nguyên lý, các bẫy thường gặp và mẹo tối ưu.

**Biên dịch code trong lời giải:**

```bash
gcc -std=c11 -Wall -Wextra -g main.c -o main -lm
./main
```
